# Energiemanagement

Privates Projekt fuer ein iterativ wachsendes Energiemanagement-System.

## Ziel

Dieses Repository ist die gemeinsame Projektakte fuer Planung, Code, Entscheidungen und laufende Optimierungen.

## Arbeitsweise

- Projektwissen wird in `PROJECT_MEMORY.md` gepflegt.
- Technische und fachliche Entscheidungen werden in `docs/decisions.md` dokumentiert.
- Offene Aufgaben stehen in `docs/todo.md` oder spaeter in GitHub Issues.
- Jede relevante Aenderung soll als Git-Commit nachvollziehbar bleiben.

## Aktueller Stand

Initiales Repository-Setup. Die fachlichen Anforderungen und die technische Zielarchitektur werden als Naechstes gemeinsam festgelegt.
